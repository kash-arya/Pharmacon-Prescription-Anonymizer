PHARMACON — HANDWRITING SAMPLE SHEETS
=====================================

WHAT THIS IS (read once — 30 seconds)
-------------------------------------
This is for a student software-engineering project on digitising handwritten
prescriptions. The system will learn your handwriting so it can read
prescriptions more accurately.

Time needed: about 15-20 minutes. Your samples are used only for this
academic project. No patient information is collected.


HOW TO WRITE (read carefully — these rules matter)
--------------------------------------------------
1. Use RULED / LINED paper (like a notebook). Not blank paper.
2. Write ONLY the numbered items below, ONE LINE per item.
3. Do NOT write section titles (like "Sheet 1" or "Characters"). Write only
   the items themselves.
4. Leave a clear, consistent gap between lines. Do not crowd them.
5. Write in the exact order given. Do not skip, merge, or split lines.
6. Do not add your own examples. Copy each item exactly as printed.
7. Use a pen, in your normal handwriting.
